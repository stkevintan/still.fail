# Working in `pion/station` (for agents)

Standalone Pion station workspace (`pion.toml`) with pinned `AFK-surf/pion` toolchain bootstrap, cross-platform C host/SQLite shims, and real `libstillfail_shell.a` static-link verification.

## Boundaries

- Keep `pion/station/` self-contained: do not depend on `pion/client-core/`, `pion/app/`, or UI packages.
- Do not modify `pion/base/`, `pion/client-core/`, or `pion/app/` from station-migration work (propose upstream `pion/base/` fixes separately). Slice-wiring PRs may update the corresponding `station/src/` switch entrypoints and `station/mb/` parity fixes alongside `pion/station/`.
- Foreign threads in `packages/host_shim/native/station_host.c` never invoke Pion callbacks; they only enqueue native events and signal the single-threaded event loop. `sth_stop` drops only `STH_EV_SHELL_DONE` events and preserves queued stdin data and EOF.
- Direct SQLite FFI in `packages/sqlite_ffi/native/station_sqlite.c` calls the `sqlite3_*` symbols bundled in `libstillfail_shell.a` without JSON serialization, behind generation-checked handle tables to prevent UAF on double-close or double-finalize.
- `--smoke-rc-soak` verifies deterministic RC reclamation and bounded RSS plateau for **acyclic object graphs** only; Pion RC does not auto-collect strong reference cycles, so long-lived station workers must break cycles via owner IDs or explicit `close()`.

## Packages and Scripts

- `TOOLCHAIN`: pinned `AFK-surf/pion` commit SHA bootstrapped by `scripts/ensure-pionc.sh`.
- `scripts/ensure-pionc.sh`: pinned upstream SHA bootstrap + local cache SHA-256 integrity verification across `pionc`, `qbe`, `libpionrt.a`, and runtime sources/headers (serialized with a lock directory).
- `scripts/build.sh`: builds `packages/smoke` (`stillfail-pion`) for `darwin-arm64`, `linux-x64` (glibc 2.28), `linux-arm64` (glibc 2.28), or `win32-x64` (MinGW GNU) linked against real `libstillfail_shell.a`.
- `packages/host_shim`: C11 POSIX + `_WIN32` host bridge (strict <= 16 MiB stdin backpressure, shell completion queue, stdout framing, args/pid/exit/RSS/fd-count) + Pion wrapper + C concurrency test (`packages/host_shim/native/host_shim_test.c`).
- `packages/sqlite_ffi`: direct `sqlite3_*` C11 FFI bridge + Pion wrapper (`open`, `prepare`, `bind_*`, `step`, `readonly`, `bind_parameter_count`, `column_*`, `reset`, `clear_bindings`, `finalize`, `exec`, `wal_checkpoint`, `wal_checkpoint_hard`) + C unit test (`packages/sqlite_ffi/native/station_sqlite_test.c`).
- `packages/sql_db`: high-level SQLite database layer over `sqlite_ffi` and `base_codec` matching `station/mb/src/sql/sql.mbt` (256-entry prepared statement cache, reset + clear_bindings, strict Int64/float/BLOB/WHATWG lossy UTF-8 binding and decoding, `Db::tx`/`Db::tx_err` transaction safety with rollback on body or commit error, `Db::deferred_tx_err` read-snapshot transactions, `Db::with_temp_write_tx` private temporary writable DB transactions, `conversation_of`, `Db::rollback_if_in_tx`, nestable `Db::savepoint_err` and `Db::savepoint_swallow_err`, `is_busy`, schema helpers). Only `sql_db.pion` (plus the low-level `sqlite_ffi` smoke helper `run_smoke_sqlite` in `packages/smoke/src/main.pion`) may contain raw transaction SQL.
- `packages/js_json`: lossless UTF-16 JSON (`JValue`, `parse`, `parse_units`, `stringify`, `stringify_line`, `stringify_with_num`, `stringify_indent`, `stringify_pretty`), pure-Pion civil-date/ISO-8601 helpers (`days_from_civil`, `civil_from_days`, `format_iso_ms`, `js_parse_iso`, `js_iso_checked`), and UTF-16 code-unit helpers (`utf16_units`, `utf16_len`, `utf16_slice`, `utf16_find_from`, `utf16le_bytes`, `sanitize_str`, `text`, `utf8_bytes`, `is_safe_integer`, `js_compare`, `js_less`, `trim_js`, `js_utf8_len`, `points`, `without_mentions`, `jval_try_parse`, `jval_arr`, `jval_at`, `jval_num_of`, `num_text`) matching `station/mb/src/jsjson/`.
- `packages/jscase`: zero-dependency V8 `String.prototype.toLowerCase()` (`İ`, final `Σ`), JS `\s` vs Unicode `White_Space` trimming/splitting, and `/[\p{L}\p{N}]/u` word checks (`station/mb/src/jscase/`).
- `packages/nodepath`: zero-dependency Node `path.posix` / `path.win32` helpers (`basename`, `dirname`, `is_absolute`, `join`, `relative_parts`, `with_extension`; `normalize` private) matching `station/mb/src/nodepath/`.
- `packages/station_conv`: lightweight shared conversation grouping (`settle_conversation_in_tx`, `owned_ws_sql`, `is_owned_ws`, `birth_threads_of`) depending only on `sql_db`/`js_json`/`base_codec` (never `builders_core`), shared by `builders_legacy` and replica restore.
- `packages/builders_core`: shared SQLite builder stdio event loop (`builder_loop` with unbounded `\n` framing, WHATWG lossy UTF-8, U+2028/U+2029 escaping, `StepError::Fallback`, `db.rollback_if_in_tx()` transaction leak guard, and `Permit` with deferred FIFO queue), unified `ShellClient` (single unbounded `LineQueue`, sync `shell_sync_json`, async `shell_call_wait`, `say_line`, `beside`, `read_bytes`, `write_atomic`, `unique_tmp`), and the 10 core SQLite builders (`archive-marks`, `session-bindings`, `session-counts`, `signin-save`, `post-blocks`, `usage-retire`, `widget-sources`, `card-posts`, `closed-cards`, `people-since`; all write transactions via `Db::tx`/`Db::tx_err`).
- `packages/transcript_io`: lightweight transcript hashing (`sha1_utf8_hex`, `sha256_utf8_hex`, `sha256_bytes_hex` over locked `crypto-v0.4.1`) and seekable zstd reader (`packed_written_size`, `packed_read_segments`) over `builders_core::ShellClient` (never depends on `packed`).
- `packages/locate`: production live transcript locator (`--builder live-locator`) with `Finder`, `Locator` (reentrant four-way state machine keyed by `id.stringify()` over `Db::deferred_tx_err` snapshots and sync `ShellClient`), `history_sources`, `claude_project`, `runtime_kind`, `transcript_dir`.
- `packages/builders_search`: production chat/job/memory/skill/profile and execution-history full-text search worker (`--builder search --db <file> --data <dir> [--sep <sep>]`) split into `search` (`search_match`, `search_docs`) and `history` (`history_classes`, `history_script`, `history_timeline`, `history_entries`, `history_transcripts`, `history_search`), implementing a resumable per-request stepper (`ActiveQuery`) across all 12 pause points with bounded 64-event stdin draining, round-robin concurrency, explicit exact-once `text.open`/`text.close` handle lifecycle, single-step temp table materialization + immediate drop before P12, and `sql_db::savepoint_swallow_err` read snapshots (zero raw tx SQL).
- `packages/builders_index`: 5 index/job SQLite builders over `sql_db` and `builders_core` (`--builder session-up-jobs` including `job_name_first_step`, `--builder workspace-up-jobs`, `--builder outflow-chats`, stateful `--builder search-scope` with per-process `turn` rotation, and `--builder session-list` with short-circuit `step && audit`; all write transactions via `Db::tx_err`).
- `packages/builders_requested`: 4 interactive/on-demand pure SQLite builders over `sql_db`, `builders_core`, `host_shim`, and `base_codec` (`--builder turn-counts` and `--builder said` with external `Permit` guard lifecycle + `savepoint_swallow_err("said_scan", ...)`, `--builder cc-index` with dual `cc`/`names` instances + `latest` lane, and read-only `--builder usage-check` with startup `complete()` check and exact numeric `id` `repr` echo; all write transactions via `Db::tx_err`).
- `packages/builders_stateful`: stateful trigger-installing SQLite builders (`archive-last`, `page-letters` including `Letters::gc_step`) holding per-process `schema_version` install caches across requests over `builders_core::builder_loop`, `sql_db::Db::tx_err`, and `base_codec` (all write transactions via `Db::tx_err`; self-contained `CREATE TRIGGER ... BEGIN ... END;` literals).
- `packages/builders_legacy`: legacy and backfill SQLite builders (`--builder legacy-edits`, `--builder legacy-said`, `--builder session-backfill` across all 19 kinds including `conversation-backfill` and `page-letter-gc` reusing `builders_stateful::Letters::gc_step`) over `builders_core::builder_loop`, `sql_db::Db::tx_err`, `js_json` UTF-16 helpers, `crypto`, and `host_shim::wall_ms` (zero raw tx SQL; only `legacy-edits` emits `StepError::Fallback`).
- `packages/builders_recent`: stateful 4-part recent-chat SQLite index builder (`--builder recent-chat`) over `builders_core::builder_loop`, `sql_db::Db::tx_err`, `sql_db::Db::savepoint_err` (read snapshots and nested per-contribution partial rollbacks), and `base_codec`, holding per-process install/tracked flags and per-scope round-robin lane turns across requests.
- `packages/builders_vault`: vault use-index, pending/member/rebox lookup builder (`--builder vault-uses`) over `js_json`, `sql_db`, `builders_core::LineQueue`, and `host_shim` (`wait=100`, `PRAGMA synchronous = NORMAL`, nestable `savepoint_swallow_err("vault_use_page", ...)`, write transactions via `Db::tx_err`, lossless UTF-16LE BLOBs, lone-surrogate & NUL preservation, `{"busy":true}` / `{"error":...}` without `id`).
- `packages/builders_usage`: production transcript usage counter (`--builder usage-counter --db <file> [--sep <sep>]`) over `sql_db` (`attach(wait=5000)`, `PRAGMA synchronous = NORMAL`, batched `Db::tx_err` commits with zero raw transaction SQL), `builders_core::ShellClient` (sync `fs.*` + async `zstd.open`/`zstd.push` + sync `zstd.close`), `transcript_io` (`packed_written_size`/`packed_read_segments`), `locate::Finder`, `nodepath`, and `js_json` (1:1 port of `usagecount/{calls,counter,files,record,speed}.mbt` + `readops/{parse_iso,usage_turns}` + raw-byte line framing + wire protocol).
- `packages/footprint`: production disk footprint worker (`--builder footprint`) with thin cross-platform C11 FFI (`packages/footprint/native/footprint_fs.c`: `lstat`, sorted `readdir`, `exists`, `is_dir`, non-blocking regular-file-only `head`, monotonic clock) + pure Pion traversal/rebuildable/budget engine + C unit test (`packages/footprint/native/footprint_fs_test.c`).
- `packages/memory`: production agent memory & shared skills worker (`--builder memory [--shell-dir <dir>] [--sep <sep>]`) in pure Pion over `host_shim` (`libstillfail_shell.a` `fs.*`), `base_codec`, and `crypto` (all 16 JSON-RPC ops, JS UTF-16 ordering/tags, 3-way line merge, union lines, blob storage, path-safe atomic skill writes, streaming pipelined stdin loop).
- `packages/packed`: production cold-storage worker (`--builder packed [--shell-dir <dir>]`) in pure Pion over `host_shim` (`libstillfail_shell.a`: `fs.meta`, `fs.bytes`, `fs.put`, `zstd.segments`, `zstd.check`, `tar.pack`, `tar.unpack`, `tar.file`), matching `station/mb/src/packed` seek-table and streaming line-JSON RPC contracts.
- `packages/smoke`: `stillfail-pion` binary (`--version` with `modes:footprint,packed,memory,archive-marks,session-bindings,session-counts,signin-save,post-blocks,usage-retire,widget-sources,card-posts,closed-cards,people-since,session-up-jobs,workspace-up-jobs,outflow-chats,search-scope,session-list,archive-last,page-letters,legacy-edits,legacy-said,session-backfill,recent-chat,vault-uses,turn-counts,said,cc-index,usage-check,live-locator,usage-counter,search`, `--smoke-stdio`, `--smoke-sqlite`, `--smoke-sql-db`, `--smoke-shell`, `--smoke-rc-soak`, `--builder footprint [--sep <sep>]`, `--builder memory [--shell-dir <dir>] [--sep <sep>]`, `--builder packed [--shell-dir <dir>]`, `--builder live-locator --db <file> --data <dir> [--sep <sep>]`, `--builder usage-counter --db <file> [--sep <sep>]`, `--builder search --db <file> --data <dir> [--sep <sep>]`, and `--builder <mode> --db <file>` for all 10 `builders_core` + 5 `builders_index` + 2 `builders_stateful` + 3 `builders_legacy` + `builders_recent` + `builders_vault` + 4 `builders_requested` modes).
